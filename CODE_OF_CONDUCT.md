# Code of Conduct

We want osustatus to be a welcoming, constructive, and respectful place for everyone.

Participation in this project—including issues, discussions, pull requests, and project spaces—comes with the following expectations:

- Treat people with respect, patience, and consideration.
- Discuss ideas and code in good faith; critique the work, not the person.
- Keep feedback focused on the project and make room for different experience levels and viewpoints.
- Do not harass, threaten, insult, bully, intimidate, or discriminate against others.
- Respect privacy. Do not publish personal information without permission.
- Keep project conversations constructive and relevant.

Project maintainers may remove content, restrict participation, or take other action when needed to protect the community and keep the project healthy.

If you need to report a concern, contact the repository owner privately through their GitHub profile rather than posting sensitive details in a public issue or discussion.
